# Markdown Printer 1.1.0

Markdown Printer now exports editable Microsoft Word documents while keeping PDF as the default preview, save, print, and drag workflow.

- Exports editable DOCX files with formatting, links, tables, Unicode, local images, and offline placeholders.
- Lets you choose PDF or Word in Settings, override the format for one save, and drag either format as a concrete file.
- Keeps PDF headings with their following content for cleaner page breaks.
- Adds compact linked footnotes with bidirectional navigation in PDF and Word.
- Preserves Markdown blockquote borders, indentation, italics, links, and footnote references in Word.

This universal macOS 14+ build is signed with Developer ID and notarized by Apple.
