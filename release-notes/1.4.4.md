# Markdown Printer 1.4.4

This update improves image support and table layout, and fixes a crash when closing document windows.

## Download Remote Images on Demand

- Click a remote-image placeholder to download that image, or right-click and choose **Download All Images** for the current document.
- Downloaded images appear in the preview and exports and are stored only in the app's disposable cache, without changing your Markdown file or its folder.
- Downloads require secure HTTPS connections and start only when you request them. Finder Quick Look remains offline.

## Better Image Rendering

- Renders standalone HTML `<img>` tags in Markdown, including local images and optional image widths, instead of displaying the tag as raw markup.
- Fits images inside tables to their actual column width, accounting for cell padding and borders while preserving aspect ratios and smaller image-size limits.
- Applies the table sizing consistently to Markdown images, linked images, HTML images, and downloaded images.

## More Reliable Window Closing

- Fixes a thumbnail-sidebar cleanup issue that could crash the app when closing a document window with **Command-W**.

This universal macOS 14+ build supports Apple silicon and Intel Macs and is signed with Developer ID and notarized by Apple.
