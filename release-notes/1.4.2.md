# Markdown Printer 1.4.2

This polish update improves everyday document handling and interaction.

- Fixes a bug that could hide **File → Open…**, **Open Recent**, and **Clear Menu** from the app menu.
- Preserves each open document window's size, position, PDF zoom, current page, and scroll position when Markdown Printer relaunches after installing an update.
- Adds **View → Fit Page** with Command-0 to fit the complete current PDF page in the window.
- Shows the PDF or Word thumbnail as soon as a hold-to-drag gesture is ready.
- Enlarges the welcome screen's document artwork for a clearer starting point.
