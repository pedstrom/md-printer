# Markdown Printer 1.0.1

Linked Markdown documents now open naturally inside Markdown Printer.

- Resolves relative links to local `.md`, `.markdown`, `.mdown`, and `.mkd` files from the source document's folder.
- Opens linked Markdown files in their own Markdown Printer windows.
- Continues to use normal macOS handling for web links and other local file types.

This universal macOS 14+ build supports Apple silicon and Intel Macs. It was distributed with an ad-hoc signature before Developer ID notarization was introduced in version 1.0.3.
