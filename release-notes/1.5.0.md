# Markdown Printer 1.5.0

Share a document with its changes marked, while keeping the current version's layout.

Choose **File > Compare with Older Version…** to supply an original Markdown file. The same document window adds yellow highlights for changed phrases, new or moved paragraphs, formatting, and changed links. Changed image references get a yellow border. **Clear Change Highlighting** returns to the ordinary document.

Removed wording appears in small red notes with strikethrough, with a caret identifying its original location. Notes prefer nearby gaps, stay inside table cells when placed there, and use connecting lines when displaced. Minor punctuation and standalone whitespace edits stay quiet. The current text keeps its wrapping and pagination, and the same markings carry through PDF preview, Save, Share, drag export, Print, and editable Word export.

For AI and command-line workflows, the app now includes an explicit opening command:

```sh
"/Applications/Markdown Printer.app/Contents/MacOS/MarkdownPrinterCLI" open current.md --original older.md
```

Without `--original`, the command opens multiple files normally. The app snapshots the original locally before returning, so a temporary Git version can be removed safely. The original stays fixed as the current file refreshes and survives session restoration. Help includes a copy-and-paste prompt for creating a reusable Codex comparison skill.

This release also restores window position, size, zoom, and exact scrolling more reliably when reopening the last session or relaunching after an update.

This universal macOS 14+ build supports Apple silicon and Intel Macs and is signed with Developer ID and notarized by Apple.
