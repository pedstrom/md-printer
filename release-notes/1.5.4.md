# Markdown Printer 1.5.4

Review comparisons with clearer grouping and move directly between the PDF and its Changes list.

## Clearer Document Comparisons

Related changes now stay together. Added or removed sections and lists appear as complete entries, paragraph replacements combine into one change, and table rows match more accurately across reorganized content.

The Changes sidebar shows consistent numbers and complete Earlier/Current passages, with matching highlights in the PDF.

## Select Changes from the PDF

With Changes open, click a changed paragraph, table row, or removal note to select and reveal its list entry. Collapsed groups expand automatically, and arrow keys work immediately to move to the next or previous change.

Text selection, copying, and links remain available. Selecting a change from the PDF keeps your reading position.

## More Recent Files

Open Recent now retains 20 files instead of 10.

Requires macOS 14 or later. Supports Apple silicon and Intel Macs.
