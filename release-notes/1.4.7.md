# Markdown Printer 1.4.7

This update adds GitHub-style links and task-list formatting, makes document sections easy to navigate, and keeps your preview available while another app rewrites or renames the source file.

## Links and Task Lists

Bare web addresses and email addresses now become clickable links automatically, including `https://`, `http://`, `www.`, `mailto:`, and `xmpp:` forms. Trailing punctuation stays outside the link, and code and existing link labels retain their original formatting.

Task lists now follow GitHub's checkbox rules more closely. Use `- [ ]`, `- [x]`, or `- [X]` at the start of a list item. Nested lists, tabs, and mixed ordinary/task lists are supported. Checkboxes remain read-only formatting.

## Jump to Document Sections

Link to `## Packing List` with `[Packing](#packing-list)`, or open a section in another local Markdown file with `[Packing](other.md#packing-list)`. Heading anchors are generated automatically for all six heading levels, with Unicode support and distinct anchors for repeated headings.

Same-document links work in the app and Finder Quick Look. PDF exports preserve native heading destinations and internal links; Word exports include heading bookmarks and internal hyperlinks. Cross-file export links remain file URLs with fragments, whose behavior depends on the receiving viewer.

Quick Look's host controls whether a cross-file link may launch the app. When macOS declines, the preview offers a notice to open the source document using the toolbar.

## Preview Through Background File Changes

When a source temporarily disappears or cannot be read, Markdown Printer keeps the last successful preview and retries automatically. After about two seconds, a compact banner says **Source file unavailable. Showing the last rendered version.** There is no repeated read-error dialog to dismiss.

The banner clears as soon as the source can be read again, even if its content is unchanged. Detected renames and moves update the source location and relative image/link resolution automatically.

This universal macOS 14+ build supports Apple silicon and Intel Macs and is signed with Developer ID and notarized by Apple.
