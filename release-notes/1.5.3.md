# Markdown Printer 1.5.3

Review document changes directly from the new Changes sidebar.

## Changes in Sidebar

After comparing with an earlier file or Git version, Changes opens with a list grouped under document headings and complete **Earlier** and **Current** passages.

- **See the complete change.** Review exact wording, including full removed passages even when the PDF annotation is shortened or summarized.
- **Navigate immediately.** Click a change, use Previous/Next, or press Down/Right and Up/Left. The selected entry receives keyboard focus when Changes opens.
- **Keep your place.** A pale yellow band and circular number identify the selected passage in the PDF preview. The band includes related removal notes and continues across pages.
- **Read with context.** Navigation leaves room above the selected passage and avoids scrolling when it is already comfortably visible.

Selection bands appear only in the preview; exported documents retain their comparison markings.

## Clearer Deletion Notes

Substantial prose removals now use concise paragraph, sentence, or word counts in PDF and Word annotations. The Changes sidebar retains the complete original wording for review.
