# Markdown Printer 1.4.0

Markdown files can now be previewed directly in Finder.

- Adds a continuous, scrollable Quick Look preview: select a Markdown file and press Space or Command-Y.
- Preserves headings, tables, lists, quotations, code, links, footnotes, selectable text, and adaptive light and dark colors without turning the preview into paginated PDF pages.
- Keeps Quick Look local and offline, with readable placeholders for remote or inaccessible neighboring images.
- Bundles the Quick Look extension inside Markdown Printer so app updates retain it and deleting the app removes it.
- Adds Finder Quick Look instructions and a standard **Open System Settings…** button to Settings.
- Adds an opt-in **Make Markdown Printer Default** action for `.md`, `.markdown`, `.mdown`, and `.mkd` files, using one macOS consent request.
- Adds a Markdown document icon when Markdown Printer is the default app.
- Adds **Check for Updates…** beside the automatic-check preference in Settings.
