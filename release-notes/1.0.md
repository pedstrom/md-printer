# Markdown Printer 1.0

Markdown Printer turns local Markdown files into polished, searchable PDFs that are ready to save or print.

- Opens one Markdown file or a whole batch, with each document in its own window.
- Formats headings, emphasis, lists, quotations, tables, code, links, and local images.
- Previews, saves, and prints the same US Letter PDF with centered page numbers.
- Keeps document content entirely on the Mac.
- Includes an MIT License linked from the About window.

This universal macOS 14+ build supports Apple silicon and Intel Macs. It was distributed with an ad-hoc signature before Developer ID notarization was introduced in version 1.0.3.
