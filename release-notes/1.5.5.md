# Markdown Printer 1.5.5

A small update with easier section navigation and more context when reviewing changes.

## Minor Enhancements

- **Clickable PDF outlines.** Mac PDFs now include a nested outline of the document's headings. In macOS Preview, choose **View > Table of Contents** to browse sections and jump directly to a heading.
- **Commit descriptions in Changes.** When comparing with a Git version, select a change to see its contributing commit titles, dates, and expandable descriptions above the Earlier/Current passages.
- **Faster Word export.** Large documents export more efficiently while preserving their formatting, sections, tables, and links.

Requires macOS 14 or later. Supports Apple silicon and Intel Macs.
