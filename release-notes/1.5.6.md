# Markdown Printer 1.5.6

Open Markdown documents with their secure remote images ready to view, and choose how those images are loaded.

## Improvements

- **Automatic image loading.** Secure remote images download automatically by default, so documents that reference online images open with those images included in the preview and exports.
- **Choose when images download.** Turn off **Automatically download remote images** in **Settings > General** to use the existing manual controls for individual images or all images in the document. Finder Quick Look stays offline.
- **Everyday refinements.** Smoother Git revision selection and improved PDF pagination keep table headers, images, and short captions together and within the page.

Requires macOS 14 or later. Supports Apple silicon and Intel Macs.
