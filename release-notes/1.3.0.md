# Markdown Printer 1.3.0

Markdown Printer can now keep itself current securely.

- Checks GitHub for stable updates once per day by default; automatic checks can be turned off in Settings.
- Adds **Check for Updates…** to the application menu for manual checks.
- Downloads an update only after you choose **Install Update** and verifies its EdDSA signature before extraction.
- Reopens Markdown documents that were open when an update was installed.
- Waits for active Save and Print sheets to finish before relaunching.

This is the first updater-enabled release. Existing installations must install 1.3.0 manually once; later releases can be installed from inside the app.
