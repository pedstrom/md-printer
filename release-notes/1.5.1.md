# Markdown Printer 1.5.1

Compare your Markdown document directly with its Git history.

Choose **File > Compare with Git Version…** to see revisions that changed the current file, with dates, commit messages, and IDs. Select a version to highlight changes in the existing document window, then save, share, or print the marked PDF—or export an editable Word document. The selected original stays fixed while the current file refreshes and when you reopen the session.

This release also includes:

- **Comparison dates in footers.** When a date footer is enabled, the current modification date appears above the original date, with yellow highlighting and red strikethrough when the displayed dates differ. Git comparisons preserve the selected commit's timestamp; comparisons with another file capture that file's modification date.
- **Narrower document windows.** Windows can shrink 40% further in width, giving you more flexibility when arranging documents side by side.
- **Clearer Codex setup instructions.** Help separates the setup prompt from its example and includes a **Copy prompt** button. Use it to configure a reusable Codex skill that sends the current and original Markdown files into Markdown Printer for comparison.
- Other bug fixes.

Git comparison uses locally available history and requires Git to be installed. Reading history and comparing never changes the repository or fetches remote history.

This universal macOS 14+ build supports Apple silicon and Intel Macs and is signed with Developer ID and notarized by Apple.
