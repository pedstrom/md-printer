# Markdown Printer 1.5.2

Move through Git history faster and keep document changes readable, even in crowded layouts.

## Smoother Git Comparisons

- **Double-click to compare.** Double-click any revision in the Git history list to select it and immediately compare it with the current document.
- **Navigate from the keyboard.** The history list receives focus as soon as it opens. Use Up and Down to choose a revision, Return to compare, and Escape to cancel.
- **New shortcuts.** Press **Control-Command-G** to open **Compare with Git Version…**, or **Control-Command-H** to clear change highlighting.

## Clearer Change Highlighting

Deletion annotations now adapt to the available space. Removed wording uses shorter excerpts when gaps or margins are narrow. When a label cannot fit, a red ellipsis marks the original deletion boundary, keeping the comparison visible while preserving the document's typography and page layout.

## Bug Fixes

- Fix comparisons refusing to open when deletion annotations or their connectors could not fit.
- Fix editable Word exports failing when deletion annotations were too wide for narrow table cells.
- Fix a quick revision selection followed by Compare using the previously selected revision.

This universal macOS 14+ build supports Apple silicon and Intel Macs and is signed with Developer ID and notarized by Apple.
