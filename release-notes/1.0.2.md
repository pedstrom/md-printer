# Markdown Printer 1.0.2

The native PDF preview is now more flexible and easier to share from.

- Refits the continuous PDF preview when the document window width changes while preserving the current scale for height-only resizing.
- Allows the complete generated PDF to be dragged from the preview to the Desktop or another app that accepts PDF attachments.
- Preserves the original Markdown filename for saved and dragged PDFs, changing only the final extension to `.pdf`.

This universal macOS 14+ build supports Apple silicon and Intel Macs. It was distributed with an ad-hoc signature before Developer ID notarization was introduced in version 1.0.3.
