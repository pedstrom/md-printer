# Markdown Printer 1.4.3

This consistency-and-polish update makes Markdown Printer feel more at home on the Mac, keeps preview and export behavior aligned, and makes larger or more complex documents smoother to work with.

## A More Native Mac Experience

- Adds standard **New Window** and **New Tab** commands, native tab-bar behavior, and reliable Command-W closing for tabs, document windows, welcome windows, and Help.
- Refines the File, Edit, View, and Window menus around Markdown Printer's read-only workflow, including **Save As…**, **Show in Finder**, and a focused **Share PDF…** or **Share Microsoft Word…** command.
- Adds a locally bundled, selectable Help window with an overview and complete keyboard-shortcut reference.
- Improves the visual consistency of welcome, loading, and PDF-preview surfaces in Dark Mode.

## A More Capable Preview

- Adds an optional PDF thumbnail sidebar that stays synchronized with the current page, scales its thumbnails as it is resized, and can be dragged fully closed.
- Adds Preview-style page navigation and zoom commands, with menu items that enable and disable accurately at page and zoom boundaries.
- Keeps Option-arrow, Space and Shift-Space page navigation alongside Command-0/9 and Command-Plus/Minus zoom shortcuts.
- Anchors the native Share sheet to the toolbar and shares the exact PDF or Word format selected for export.

## Consistent Page Setup and Output

- Adds native **Page Setup…** and **Print…** commands, with per-document paper, orientation, and scale reflected consistently in the preview, saved and shared files, dragging, printing, and Word export.
- Reorganizes Settings into General and Page sections, with a reusable default Page Setup and an immediate **Use Default Page Setup** action for documents with custom settings.
- Adds configurable left and right footers for dates, document titles, filenames, or custom text while preserving centered page numbers in PDF and editable Word output.

## Reliable Workspace Continuity

- Adds **Reopen Windows from Last Session**, restoring document windows, tabs, selected tabs, window placement, zoom, page and scroll position, thumbnails, and page setup.
- Preserves the same richer workspace state during automatic update relaunches while continuing to keep document content local.

## Broader Markdown Support and Smoother Performance

- Substantially expands CommonMark compatibility across headings, code spans and blocks, line breaks, nested and loose lists, block quotations, reference links and images, autolinks, entities, and inert raw HTML.
- Reuses parsed document structure across preview and exports, moves suitable preparation work off the main thread, and improves cancellation and Word-export efficiency so large documents remain responsive.
