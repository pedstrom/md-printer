# Markdown Printer 1.2.0

Markdown Printer now refreshes open Markdown files seamlessly and includes native PDF search.

- Refreshes open documents automatically when their Markdown source changes.
- Keeps the visible PDF painted while a replacement is rendered, positioned, and swapped into place.
- Preserves window size, zoom, reading position, and page-boundary placement across edits, including table changes.
- Finds rendered PDF text with Command-F, moves between matches with Command-G and Shift-Command-G, and keeps the movable search panel out of the document's way.
- Opens new documents at the true top of page one and keeps document titles stable during refreshes.

This universal macOS 14+ build is signed with Developer ID and notarized by Apple.
