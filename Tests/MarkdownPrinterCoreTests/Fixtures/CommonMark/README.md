# CommonMark 0.31.2 test subset

`selected-examples.json` contains the normative examples from the seven
CommonMark sections exercised by Markdown Printer's missing-feature
conformance tests. It was extracted from the tagged CommonMark 0.31.2
`spec.txt` using the official test format.

- Source: <https://github.com/commonmark/commonmark-spec/tree/0.31.2>
